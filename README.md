# Kanban

A simple kanban board for organizing tasks into columns you can drag cards between....
Built with plain HTML, CSS and JavaScript 
no frameworks, no build step, no dependencies.

## Features

- Multiple boards ..... create, rename, delete, switch between them from the sidebar
- Columns and cards..... add, edit, delete, drag to reorder or move between columns
- Cards support priority (low/medium/high), due dates, labels, and a checklist....
- Search and filter cards by title, label, or priority
- Drag and drop for both cards and columns
- Column color tags and WIP limits
- Light/dark theme toggle
- Undo/redo (Ctrl+Z / Ctrl+Shift+Z)
- Export/import your board data as JSON
- A small stats panel showing cards per column
- Everything saves to localStorage automatically, no backend needed

## Keyboard shortcuts

- N - add a card to the first column
- Esc - close whatever modal is open
- Ctrl+  Cmd+Z - undo
- Ctrl+Shift+Z  Ctrl+Y - redo

## Running it

No install, no build step. Just open the link  in a browser and try using it
